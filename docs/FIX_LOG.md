## Still open (not fixed here)

- `npm audit`: triaged in `docs/DEPENDENCY_AUDIT.md`. Dev-only findings remain in the web tooling (Vite, Vitest, Tailwind) and four root advisories in the mobile toolchain, two of which have no patched release yet.
- Web tests now cover signup and login. Other pages (medicines, dashboard, wellness) still have no page-level tests.
- The reported "confirm password auto-fills" symptom could not be reproduced in code: the two fields use separate state and a test proves they stay independent. If it happens in a real browser, the likely cause is the browser or password manager filling both `autocomplete="new-password"` fields; this needs a manual check in a browser with the password manager off.
- Email (SMTP) and remote push delivery are unverified end to end.
- Migration tracking table does not exist; `repair_additive.sql` is the interim path for old databases.
- Everything above was tested on MariaDB 10.11, not 10.4.32.
- A stray `HealthPredict_round3_progress.zip` (about 4 MB) sits in the project root and should be deleted.
